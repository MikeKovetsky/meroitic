# Griffith's Latin letters of 1922 and the transliteration you write

He uses two ways of writing Meroitic in Latin letters in this article.

## 1. In his notes on the formulae (pp. 647-648) and in a few notes: his transliteration

One letter (or letter with a mark) for each sign:

| He prints | You write | Example |
|---|---|---|
| ê | o | atê -> ato |
| tê | to | |
| te | te | |
| š | s (the s sign) | pšê -> pso |
| s | se (the se sign) | |
| ñ | ñ | |
| z | d | |
| h with a line below (h̲) | ẖ | mh̲e -> mẖe |
| h with a curved mark below (ḫ, ḫ) | ḫ | yelḫte -> yelḫte |
| every other letter | the same letter | |

## 2. In his English renderings of names and titles

An English-style spelling, not one letter per sign:

| He prints | You write | Example |
|---|---|---|
| sh | s (the s sign) | Wêsh -> wos |
| s (alone, not in sh) | se (the se sign) | pesatê -> peseto (corpus pesto); Pakharas -> pẖrse |
| kh | ẖ | Pakharas -> pẖrse; Makheye -> mẖeye |
| ch | ḫ | charapachañ -> ḫrpḫñ |
| ê | o | Malêwitar -> mlowitr |
| ñ | ñ | |
| z | d | Nakazeyê -> nkdeyo |
| a between consonants | nothing: he adds it where the script writes no vowel sign | Pakharas -> pẖrse |
| A at the start of a word | the sign a | Ashêri -> asori (the stone may have asori, sori or soreyi) |
| every other letter | the same letter | |

So his English renderings tell you the consonants and the vowel signs e, i, o, but not where the script has the
sign a inside a word. He capitalises names. Words he could not render are left out or shown as gaps ("[...]").
