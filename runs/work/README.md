# Agents' working files

Copied from the agents' scratch folders on 2026-11-09, text files only (page images, PDFs and crops left out:
they come back from archive.org by the item ids in `data/expansion/README.md`). These are working files, not
reviewed code: the reviewed pipeline is `src/`.

- `griffith/`: the transcription of Griffith's printed type: the 12-text accuracy test (readings saved before the
  FHN text was opened), and per share (`mi1a`, `mi1b`, `mi2a`, `mi2b`, `meroe`) the crop scripts, the readings and the
  builders that wrote `data/expansion/griffith_*.jsonl`.
- `handcopy/`: the Karanòg hand-copy test: `readings.md` (eight readings with timestamps, frozen before FHN was
  opened) and the scoring script behind `data/expansion/hand_copy_test.md`.
- `vision/`: the photograph test behind `data/discovery/vision.md`, with the download manifest (URL, licence, size).
- `gold_builders/`: the scripts that wrote `data/gold_lexicon.json` and `data/gold_morphology.json`.
